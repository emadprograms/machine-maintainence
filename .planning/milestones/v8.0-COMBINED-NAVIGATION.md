# Milestone v8.0 — Combined navigation

## User decisions
- Replace the separate Due soon section with one Maintenance list, filtered by All schedules, Due soon and Overdue. Preserve the 7/14/30/90-day windows and completion actions.
- Replace the separate History section with Machines and History tabs within Machines. Retain workshop-wide closed-job history, its filters and CSV, and every machine's own history dialog.
- Execute autonomously without deleting or changing existing data.

## Delivered
- Maintenance filters the same in-service schedule list, including overdue jobs in the due windows. The dashboard card opens the seven-day filter. Retired machines' schedules remain parked. The shared table preserves dates, sorting, new schedules and mark-done actions.
- Schedule creation loads its own in-service machine choices, including on the first visit from the dashboard; loading, no-machine and error states disable submission, offer retry and ignore stale responses.
- Machines contains accessible keyboard-navigable tabs. Workshop history retains search, date filters and CSV, while per-machine history still includes open and completed jobs and links to timelines.
- API data and old due endpoint are retained; the dashboard link now points to Maintenance. Failed schedule fetches are not presented as an empty list.

## Verification
- Full smoke, offline audit, UI and integration/migration suites run sequentially. Chromium desktop and 320px mobile exercised the dashboard shortcut, due windows, completion, creation without visiting Machines, lookup failure and retry, history filters, keyboard tabs and per-machine history.
