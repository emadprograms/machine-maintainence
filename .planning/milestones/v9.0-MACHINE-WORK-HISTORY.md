# Milestone v9.0 — Machine and work-order history

## Decisions
- Machines has Machines and Machine history tabs. Work orders has Open work orders and Work order history tabs; the latter includes all statuses.
- Machine history combines work orders (including open and in-progress orders) and completed scheduled maintenance. Every future scheduled completion is recorded. Only the previously stored last completion of each older schedule can be migrated; it is explicitly marked last known.
- Date filtering uses inclusive overlap: work reported on/before the end and not closed before the start, including open jobs. The job-start column uses the first recorded stage; the reported column is separate. Scheduled maintenance uses its completion date. Filters include category, multiple selected machines, status and search. Both views print the exact sorted, filtered table and offer CSV.
- The standalone Reports section is removed. History tabs provide table and individual-job printing; prior monthly, machine, job and inventory reports remain under Additional reports in Work order history. All service costs remain parts-only.

## Verification
- API tests cover migration, repeat restart, completion recording, invalid dates and IDs, multiple machines, categories, status, overlap, exports and authentication. UI tests cover safe printing, filters, stale responses and error handling.
- Chromium desktop and 320px mobile exercised both history tabs, open/closed orders, scheduled maintenance, overlap, category and machine selection, sorted print-table parity, job timelines, reopening and existing additional reports.
