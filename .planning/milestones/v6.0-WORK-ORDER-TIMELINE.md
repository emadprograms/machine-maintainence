# Milestone v6.0 — Work-order timeline and close experience

## Decisions
- Work-order actions: View updates, Add update, Print job, other applicable actions, then Close job; recognizable icons on every action. Add update starts an open job using the existing stage flow.
- Show an actual chronological timeline: original fault report and photograph, stages in sequence, and a closure event when closed. Keep latest-stage admin controls and photo preview.
- Closing requires explicit confirmation that the machine is running; out-of-service cannot be closed. A closing note is optional. No hours, parts or verification input at closure. Record the running state as a new machine-state event; preserve historical hours, parts and verifications.
- Make the new-work-order form calmer, spacious and responsive without removing functionality.
- Clarify machine service-hours heading and machine-details action. Replace the machine photograph removal checkbox with an intuitive removable preview; removal is only saved on Save and can be undone.
