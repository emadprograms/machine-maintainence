# Phase 14 — The record: history you can read back

## Goal

`work_orders.closed_at` has been stored since v1.0 and no screen has ever shown a
completed job. This phase makes the past visible: a machine's own timeline, and a
History screen for finished work across the workshop, narrowable to a date range.

## Decisions

* **One endpoint, two views.** A machine's history and the workshop's history are the
  same query with a different filter. Two queries would drift; one filter cannot.
* **A filter module, not a route body.** `history-query.js` holds the only copy of
  "closed between two dates", so phase 15's CSV export can reuse it. This is the
  accepted cost recorded in `v3.0-REQUIREMENTS.md`.
* **Dates move to `dates.js`.** The range needs the same `parseDay` the completion-date
  field already uses; two copies would let one accept `2026-02-30`.
* **The list is capped at 500, the count is not.** `{ rows, total, shown }` lets a
  screen say how much of the past it is showing instead of quietly truncating.
* **`history.js` is a module**, like `shell.js` and `dashboard.js`. `app.js` is 535
  lines; the sidebar list stays the one place that knows which screens exist.

## Work

1. `dates.js` — `nowStamp` and `parseDay` extracted from `server.js`, unchanged.
2. `history-query.js` — `historyFilter()` with `equipment_id`, `status`, `from`, `to`;
   `historySql()` returning the row query and the count query.
3. `server.js` — `GET /api/history`, returning `{ rows, total, shown }`.
4. `public/history.js` — the History screen (closed jobs, date range, summary line) and
   the machine-history dialog; three distinct empty states.
5. `public/index.html` — History section, machine dialog inside the Machines section,
   `.cell-error` and `.summary-line` rules.
6. `public/app.js` — sidebar entry, `loadHistory` wrapper, a History button per machine.
7. `scripts/smoke-test.js` — ten assertions, and the static client checks now scan all
   four modules instead of `app.js` alone.

## Proof

Ten new assertions (205 → 215). Mutations: ignoring the date range, and forcing history
to closed-only, each failed its own assertion.
