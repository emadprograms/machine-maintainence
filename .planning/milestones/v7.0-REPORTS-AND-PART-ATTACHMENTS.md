# Milestone v7.0 — Central reports and spare-part attachments

## Decisions from the user
- Move Print job out of the work-order row menu into Reports, where report types are generated.
- Keep the monthly closed-work report and add printable work-order, individual machine service, and spare-parts stock reports. Machine service events are all work orders; show status counts, hours and parts-only costs. No sales/revenue tracking or labour costs.
- Spare-part catalog records support photos, videos and PDF/Word receipts/documents, not individual stage usage attachments.
- Make the stage job-report attachment an expandable section like the parts and media sections.
- Execute autonomously, preserving historic data, security, stage/stock semantics, offline use and prior behavior. Commit and push the existing branch.

## Delivered
- Reports hub generates work-order print/PDF, monthly completed work, all-time machine service, and current spare-parts inventory. The three aggregate reports have CSV and print/PDF output; machine and inventory filters affect screen, CSV and print identically. Missing inventory unit prices are identified and excluded from known stock value.
- Added up to 20 catalog attachments per part, streamed and signature-validated as media or PDF/Word, with authenticated ranged media access and safe document downloads. Create/edit associates pending uploads transactionally; removing or deleting parts cleans files. Existing stock-use deletion restrictions remain. Temporary files are owner-scoped and expire; cancellation and stale dialogs cannot save another draft.
- Stage job report is an accessible expandable section. Existing stage reports, timeline, latest-stage admin restrictions and stock reconciliation remain unchanged.
- Database migration creates the attachment table without changing existing rows. Database backups require copying the `photos` folder separately, now including part attachments.
