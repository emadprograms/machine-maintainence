# v5.0 — Work-order experience and print

Status: completed 2026-11-05.

## Goal
Make staged work easy to review and correct, preserve the original problem once work begins, and provide a complete printable job record.

## Agreed scope
- Refine the design of spare parts in the stage editor without changing its existing table, quantity grouping, actual-price or transactional stock behavior.
- Show stages as readable timeline cards with photo thumbnails and an enlarged preview; support previewing existing and newly selected stage photos during correction.
- Place the machine-running switch beside time spent; preserve explicit latest-state semantics and the stage edit rules.
- Hide work-order Edit once a stage exists and enforce the lock on the server for original report fields and fault-photo changes. Updates, latest-stage correction, reassignment needed by stage entry, closure and reopening remain possible. If all stages are permanently deleted, the original report is editable again.
- Add Print job to the work-order three-dot menu. Open a print-ready job with complete report, closure details, totals, all stages, parts and photos. The browser print dialog provides printing or Save as PDF; no network services or installed dependencies.

## Verification
- Automated UI, API, permissions, migration and offline tests; preserve prior work-order/stock/photo coverage.
- Real browser checks at desktop and phone widths for editing parts, timeline/photo preview, lock, print preview and generated PDF content including images.
