# Milestone v1.1 — Operable — Audit

## Verdict

**passed.** All 19 requirements are implemented, all four phases carry a passing
verification report against the current source, and an independent end-to-end
run exercising every requirement as a user would scored **45/45**.

*The audit ran inline: the milestone-auditor agent is not installed in this
environment (`agents_installed: false`). Evidence is live probes and the smoke
suite, not a delegated review.*

## Cross-phase behaviour

Verified on a single server with all four phases in place — the failure mode
this catches is a later phase quietly breaking an earlier guarantee:

- parts CRUD, ownership, dates, exports and the throttle all working simultaneously;
- the login throttle does not obstruct the technician flows that phases 8–9 test;
- the shared work-order filter builder introduced in phase 9 keeps phase 8's
  `LEFT JOIN`, so a departed technician's name still renders on their old jobs.

## Test suite

**145 checks, 0 failures**, run with `PATH=/nonexistent` so any accidental
shell-out fails rather than silently differing across platforms. It rose from
67 at the start of the milestone.

Every assertion added during v1.1 was proved to fail with its defect
reintroduced. Nine assertions were found **incapable of failing** and rewritten —
this is recorded per phase rather than quietly fixed, because an assertion that
cannot fail reports safety it never checked.

## Gaps and accepted risks

No requirement gaps. Accepted, with reasons in each phase's security report:

| Ref | Accepted risk |
|---|---|

| AR-8-01 | No per-edit audit trail on work orders (deferred to v1.2) |

| AR-9-01 | CSV is buffered in memory; unreachable at workshop volumes |
| AR-9-02 | Exports are readable by technicians, mirroring the lists exactly |
| AR-9-03 | Non-numeric numeric filters coerce to no-match rather than erroring |
| AR-10-01 | The throttle cannot deploy behind a reverse proxy as-is |
| AR-10-02 | Distributed guessing is not detected |
| AR-10-03 | The 429 discloses the wait to the address that caused it |

## Not verified anywhere

- Concurrent edits from two users (deferred; last-write-wins is the documented behaviour)
- Real spreadsheet applications opening the exports (the bytes are asserted)
- The suite on Windows (`*.bat` is CRLF-pinned; the CSV's CRLF is built from escapes)
- Layout at narrow widths, including the new owner dropdown and date field
